# mtty v0.3.17

v0.3.17 为每个标签/会话分组新增独立背景色：侧栏分组与顶部标签不再共用同一种
界面外壳底色，可以一眼区分。

## 每个分组一种背景色

会话早已支持命名分组——侧栏里的一节、标签上的 `[分组]` 前缀、分组之间的分隔
线——但所有分组都画同一种中性底色。`config.toml` 新增 `[groups]` 表，把分组名
映射到 `#rrggbb` 颜色：

```toml
[groups]
miao = "#3a2f4a"
embrix = "#20343a"
```

该颜色会填充分组的标签 chip 与侧栏会话行。活动行会提亮，悬停行提亮幅度较小，
因此原有的活动/悬停提示仍然可见，同时分组保留自己的颜色。没有配置的分组保持
主题原本的填充；不含 `[groups]` 的配置与之前渲染完全一致。

分组色表每帧从已加载的配置读取一次；修改 `config.toml` 在下次启动时生效。

## 验证

`cargo test -p mtty-config --lib`（44 个测试）与 `cargo test -p mtty-ui --lib`
（190 个测试），`cargo clippy -p mtty-config -p mtty-ui -p mtty-widget
--all-targets`，以及 `cargo fmt --all --check`。新增测试覆盖 `[groups]` 解析
（非法颜色被忽略）与填充规则（未配置保持原色；配置后活动/悬停提亮）。

安装包：macOS ARM64 与 Intel ZIP；Linux x86-64 tar.gz、AppImage 与 deb；Windows
x86-64 ZIP 与 MSI。现有 macOS 签名与公证保持不变。
