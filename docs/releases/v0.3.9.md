# mtty v0.3.9

[简体中文](v0.3.9.zh-CN.md)

## Agent footer facts keep their colour

When an agent merges its status strip into the host footer and names a
semantic tone for each fact (miao 0.4.9 and newer), the merged row paints
that fact in the matching palette colour: accent for the model, muted for
the provider and a settled approval policy, warning for a blocking
approval, plus success and error. An agent that reports no tone — every
release before this one — keeps the row's normal text colour, so the
footer looks exactly as it did until the agent also ships the field.

## Maintenance and verification

Cross-platform CI covers Linux, macOS and Windows, along with rendering and
release-mode performance gates.

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. Existing macOS signing and notarization remain
in place.
