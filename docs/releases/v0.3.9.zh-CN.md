# mtty v0.3.9

[English](v0.3.9.md)

## 代理底栏事实保留各自的颜色

当代理把状态条合并进宿主底栏、并为每个事实点名语义 tone（miao 0.4.9 及以上）时，合并行会按对应调色板给该事实上色：模型用 accent，provider 与已结算的批准策略用 muted，阻塞中的批准用 warning，另有 success 与 error。未上报 tone 的代理——本次之前的所有版本——继续使用该行的正常文字颜色，因此在代理也发布该字段之前，底栏表现与今天完全一致。

## 维护与验证

跨平台 CI 覆盖 Linux、macOS 与 Windows，并包含渲染与 release 模式性能门。

安装包：macOS ARM64 与 Intel ZIP；Linux x86-64 tar.gz、AppImage 与 deb；
Windows x86-64 ZIP 与 MSI。既有 macOS 签名与公证保持不变。
