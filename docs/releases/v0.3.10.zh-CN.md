# mtty v0.3.10

[English](v0.3.10.md)

## 面板卡片公开自己的底色

每个面板都是一张圆角卡片：卡片本身和它的内边距画的是宿主的背景色，
里面的网格属于应用。全屏 TUI 会自己填满每一格，于是一旦它按自己的
颜色铺底，页面和卡片边缘之间就留下一圈宿主背景，看起来像是应用把可用
区域缩小了一块。

新开的面板现在会在环境里带上 `MTTY_TERM_BG`：这张卡片（含内边距）的
`#rrggbb` 颜色。应用按这个颜色铺底，就能与卡片严密贴合、不再有色环。
忽略该变量的应用渲染与之前完全一致，因此在 agent 侧也采用它之前不会有
任何变化。

## 维护与验证

跨平台 CI 覆盖 Linux、macOS 和 Windows，并包含渲染与 release 模式性能门槛。

安装包：macOS ARM64 与 Intel ZIP；Linux x86-64 tar.gz、AppImage 与 deb；
Windows x86-64 ZIP 与 MSI。macOS 原有签名与公证保持不变。
