# mtty v0.3.17

[简体中文](v0.3.17.zh-CN.md)

v0.3.17 adds a colour per tab/session group: the sidebar sections and tab chips
can now be told apart at a glance instead of sharing one chrome background.

## A background per group

Sessions have had named groups — a section in the sidebar, a `[group]` prefix on
the tab, a divider between groups — but every group painted the same neutral
fill. A new `[groups]` table in `config.toml` maps a group name to a `#rrggbb`
colour:

```toml
[groups]
miao = "#3a2f4a"
embrix = "#20343a"
```

The colour fills that group's tab chips and sidebar session rows. Active rows
are brightened and hovered rows a little less, so the existing state affordance
stays visible while the group keeps its colour. A group with no entry keeps the
theme's fill, and a config without `[groups]` renders exactly as before.

The map is read once per frame from the loaded config; changing `config.toml`
takes effect on the next start.

## Verification

`cargo test -p mtty-config --lib` (44 tests) and `cargo test -p mtty-ui --lib`
(190 tests), `cargo clippy -p mtty-config -p mtty-ui -p mtty-widget
--all-targets`, and `cargo fmt --all --check`. New tests cover `[groups]`
parsing (invalid colours are ignored) and the fill rule (unset keeps the old
colour; set brightens for active and hover).

Packages: macOS ARM64 and Intel ZIP bundles; Linux x86-64 tar.gz, AppImage and
deb; Windows x86-64 ZIP and MSI. Existing macOS signing and notarization remain
in place.
