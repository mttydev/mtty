# mtty v0.3.11

[简体中文](v0.3.11.zh-CN.md)

## The grid meets the card's bottom edge

Every pane is a rounded card padded inside. The cell grid inside it used to
grow downward from the top of that padded area, so whatever height the row
count did not use piled up **below** the last row: the visible gap under a
full-screen page was the padding plus a remainder of anything from zero to a
whole extra row, and it changed with the window height.

That matters most where a page puts something on its last row and nothing
below it — an agent's input box with its chord hint. The gap under it read as
a margin the page had chosen, and it grew when the window did.

The grid is now anchored to the card's bottom edge. The remainder moves above
the first row, where a scrolled transcript hides it, and the inset under the
page is the padding alone.

## A tighter card ring

With the inset exact, the ring can be tightened without guessing: the padding
goes from 8 to 6 points and the margin between cards from 6 to 4. The inset
under a full-screen page falls from 23 points to 18 at a 929-point window,
while text still clears the rounded edge by six points.

Trimming the padding alone would have done the opposite — the freed height
became a longer remainder under the last row — which is why the anchoring
change ships with it.

## Also

- Every sizing and hit-test path shares the anchored grid: drawing, resize,
  mouse reports, the context menu's cell, and an editor's caret. A click still
  lands on the cell the renderer painted.
