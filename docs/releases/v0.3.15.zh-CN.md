# mtty v0.3.15

v0.3.15 是修内置输入法组合显示的补丁。组合串浮块和系统候选窗此前跟随面板的实时光标，全屏程序绘制时它们会被画到当前绘制到的位置，在面板里来回乱跳。现在它们停在最近一个完整帧的光标处。

## 组合串停在你输入的位置

面板输出按 UI 帧消费，有固定预算（64 KB / 4 ms）。全屏程序的一帧可能比这更大，此时组件会画一个“半帧”：实时光标在绘制到的任意位置。输入法的组合串浮块和候选窗都以这个光标定位，于是它们被画到面板中间并随着每次重绘移动——打字时最明显，因为每次按键都会让程序重绘。

终端现在记录“最近一次排空输出时的光标”，以光标为锚点的浮层改用它。一次就能排空的绘制仍会让锚点每帧更新，所以浮块会跟着光标走；跨多次消费的突发输出则保留上一次的稳定位置，直到队列排空——那也正好是这一帧自己的光标。

同步输出（`?2026`）本可以避免这个问题，但 Windows 的 ConPTY 会重新编码整屏、不转发这些标记，所以能做的就是把锚点稳住。

## 验证

`cargo check -p mtty-core` 与 `cargo test -p mtty-core`（96 通过、1 忽略）。组件侧只是把两处浮层的锚点换成新访问器；发布构建会为每个平台编译它。
