# mtty v0.3.16

[简体中文](v0.3.16.zh-CN.md)

v0.3.16 is a patch for the visible cursor. The block used to follow the pane's
live cursor, so while a long frame (a scroll repaint, streaming output) was
being applied it was drawn at whatever column the paint had reached and twitched
across the pane. It now stays at the cursor of the last complete frame.

## A block that stays where the caret is

Output from a pane is drained per UI frame with a bounded budget (64 KB / 4 ms).
A full-screen program's frame can be longer than that, and then the widget paints
a partial frame: the live cursor is wherever that paint has got to, and the block
was drawn there.

The block now uses the settled cursor — the position as of the last drain that
left no output queued — the same anchor the IME overlays got in v0.3.15. Frames
that finish within one drain still move it every UI frame, so the block follows
the caret as you type.

## Verification

`cargo check -p mtty-core` and `cargo test -p mtty-core`; the release build
compiles the widget for every platform.
