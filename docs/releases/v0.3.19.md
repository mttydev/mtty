# mtty v0.3.19

[简体中文](v0.3.19.zh-CN.md)

v0.3.19 closes the last gap left by v0.3.18's solid rules: a program that draws
its rule with the ASCII `|` still showed a dashed line.

## The pipe that is a rule

miao draws the rule beside its sidebar as `|`. It is the one vertical rule
whose width every console agrees on, but its stem is short for the same reason
`│` is, so a column of them left the same gaps.

A `|` cell whose neighbour above or below carries the same glyph now fills the
same 1 px bar as `│`, so a vertical run becomes a solid rule while a lone pipe
inside prose keeps its own shape. `║` and `═` join `┃` and `━` in the
double-line fill.

## Verification

`cargo check -p mtty-widget`; the release build compiles it for every platform.
