# mtty v0.3.12

## 按下与拖动共用一套网格

v0.3.11 把每个窗格的字符网格锚定到卡片下沿，发布说明里写着所有命中测试都读取这套锚定网格。有一处没有：用于锚定选区的**按下**仍在读卡片内边距的顶部，而延伸选区的**拖动**读的是网格。两者的差值就是行数取整用不掉的那部分高度（最多一整格），它现在位于第一行**上方**、卡片顶部留白之内。

落在这一带里的点，按下时被算成第一行，移动时却不算任何一行。于是一次单击会画出**两行空白选区**：一行从按下列到行尾，下一行从行首到同一列。

本次修复让按下、拖动和窗格右键菜单都命中同一套锚定网格，点击落在渲染器画出的那一格上。

## 单击不再等于选中

按下后指针始终没有离开所在格时，过去会留下一个单格选区。现在只有指针跨到另一格才开始选区：静止单击不选中任何内容，也不会写入剪贴板。

## 其他

- 网格上方的余量属于卡片顶部留白，不属于任何一行：在那里按下不会锚定任何内容，直到指针移进某一行。
