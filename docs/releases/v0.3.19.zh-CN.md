# mtty v0.3.19

v0.3.19 补上 v0.3.18 实心规则线留下的最后一种情况：用 ASCII `|` 画分隔线的程序，仍会显示成虚线。

## 当竖线是一条规则

miao 侧栏旁的分隔线画的是 `|`。它是唯一一种在所有控制台里宽度都一致的竖线字符，但和 `│` 一样，字形笔画比行高短，一列排下来依旧留缝。

现在，上下相邻单元格也是同一个 `|` 时，该格会和 `│` 一样补一条贯穿整格的 1px 实心细条：竖排连成一条实线，而正文里单独的管道符保持自己的形状。`║`、`═` 也加入 `┃`、`━` 的双线补条。

## 验证

`cargo check -p mtty-widget`；发布构建会为每个平台编译。
