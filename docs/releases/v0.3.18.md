# mtty v0.3.18

[简体中文](v0.3.18.zh-CN.md)

v0.3.18 is a patch for the straight rules a full-screen program draws — the rule
between two columns, the box around an input. They read as dashed lines: the
renderer drew the font's glyph per cell, and with a line height larger than the
glyph's ink every row left a gap at the cell boundary.

## Rules that meet

Each `│`, `┃`, `─` and `━` cell now also fills a 1–2 px bar across the whole
cell in the cell's own ink, so adjacent rows and columns meet exactly; the glyph
stays underneath. Corners and junctions keep their glyphs, which already reach
the cell's edges.

The change is in the renderer, so it covers every program in a pane.

## Verification

`cargo check -p mtty-widget`; the release build compiles it for every platform.
