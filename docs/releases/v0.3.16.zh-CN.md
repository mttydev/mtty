# mtty v0.3.16

v0.3.16 是修可见光标的补丁。光标方块此前跟随面板的实时光标：一个较长的帧（滚动重绘、持续输出）还在应用时，它会被画到当前绘制到的列，在面板里抽搐。现在它停在最近一个完整帧的光标处。

## 光标停在你输入的位置

面板输出按 UI 帧消费，有固定预算（64 KB / 4 ms）。全屏程序的一帧可能比这更长，此时组件会画一个“半帧”：实时光标在绘制到的任意位置，方块也被画在那里。

方块现在使用“稳定光标”——最近一次排空输出时的位置，也就是 v0.3.15 给 IME 浮层的同一个锚点。一次就能排空的帧仍会让它每帧更新，所以打字时方块会跟着光标走。

## 验证

`cargo check -p mtty-core` 与 `cargo test -p mtty-core`；发布构建会为每个平台编译组件。
